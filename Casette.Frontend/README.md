# Casette — Angular Frontend

Your private cinema. Built with Angular 17, HLS.js, and Google Cast.

## Prerequisites

- Node.js 20+
- Angular CLI: `npm install -g @angular/cli`

## Setup

```bash
npm install
```

## Configuration

### TMDB API Key
1. Create a free account at https://www.themoviedb.org
2. Go to Settings → API → Request an API Key
3. Copy your key into `src/environments/environment.ts`:

```ts
tmdbApiKey: 'your_key_here',
```

And the same into `environment.prod.ts` for production builds.

### API URL
Update `apiUrl` in both environment files to point at your ASP.NET backend.

## Running locally

```bash
npm start
```

Runs on http://localhost:4200. API calls are proxied to http://localhost:5000
via `proxy.conf.json` — make sure your Aspire AppHost is running.

## Building for production

```bash
npm run build:prod
```

Output goes to `dist/casette/`. Point Nginx at this folder.

## Project Structure

```
src/app/
├── core/
│   ├── guards/          # Route protection
│   ├── interceptors/    # JWT attachment
│   └── services/
│       ├── auth.service.ts     # Account key login, remember me
│       ├── graphql.service.ts  # All GraphQL queries to ASP.NET
│       └── tmdb.service.ts     # TMDB metadata + image helpers
├── features/
│   ├── auth/            # Login page (account key + remember me)
│   ├── library/         # Browse grid with TMDB posters + hero
│   └── player/          # HLS player + Chromecast + progress saving
└── shared/
    ├── components/      # MediaCard
    └── models/          # TypeScript interfaces
```

## Chromecast

Casette uses the Google Cast Default Media Receiver, which supports HLS natively.
No Cast developer account needed. The Cast button appears automatically in the
player when a Chromecast is detected on your network.

## Mobile

Casette is a PWA. On iOS/Android, visit the site in the browser and use
"Add to Home Screen" to install it as an app. It will launch fullscreen
with the correct theme colour and support landscape video playback.

## Login

Users log in with a random access key generated by the admin panel (in the
ASP.NET backend). No email address required. The "Remember me" checkbox stores
the token in localStorage so the browser remembers them across sessions.
Without it, the session ends when the tab is closed.
